# io_object_mu_drag_drop
Blender addon which adds drag-and-drop support for the [KSP Mu blender plugin](https://github.com/taniwha/io_object_mu)

## Install
* Download the repository source code as a ZIP file
* In Blender, Open File > Preferences
* In the Add-ons tab, Click Install, and select the downloaded ZIP file
* Done!

## Usage
Drag and drop .Mu files into Blender to import them. To adjust import settings, hold shift.
